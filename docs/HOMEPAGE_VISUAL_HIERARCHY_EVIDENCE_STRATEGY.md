# Homepage Visual Hierarchy / Evidence Strategy

## Status

This document defines the visual hierarchy and evidence strategy for the Mall Agro homepage after the refined homepage messaging baseline.

This is a planning document only.

No source implementation is approved by this document alone.

No image generation is approved by this document alone.

No public claim expansion is approved by this document.

## Current Homepage Visual State

The homepage currently uses:

* a legacy video background in the Hero section;
* static abstract visual placeholders in selected homepage sections;
* icon-based category cards;
* mostly text-led B2B section structure.

The current visual system is acceptable as a working baseline, but it is not final visual proof.

## Strategic Visual Objective

The homepage should visually communicate that Mall Agro works across:

* agricultural equipment;
* grain processing and grain handling;
* food industry equipment;
* production lines;
* material flow;
* equipment planning;
* logistics coordination;
* project-oriented industrial support.

The visual strategy must support credibility without creating unsupported claims.

## Claim-Safety Rules

Do not show, claim, imply, or visually suggest:

* official representative status;
* exclusive distribution;
* named manufacturer partnerships;
* public Cimbria or Bühler claims under Mall Agro;
* market leadership;
* guaranteed delivery;
* turnkey or EPC responsibility;
* stock availability;
* instant quotation;
* exact capacities;
* exact machine models;
* client names;
* confidential project references.

Avoid visible or readable:

* manufacturer logos;
* client branding;
* certificates;
* control-panel brand names;
* location-specific signs;
* confidential project details.

## Hero Visual Strategy

### Current State

The Hero currently uses a legacy video from the old Mall Agro website.

The same video is used across desktop, tablet, and mobile.

The video is not well adapted below approximately 1012px.

It is acceptable temporarily, but it should not be treated as final visual proof.

### Current Issue

The video leans strongly toward agriculture.

It does not fully represent:

* grain handling;
* grain processing;
* food industry equipment;
* production lines;
* industrial project capability.

### Future Direction

The final Hero should be evaluated later as one of the following:

1. optimized desktop video;
2. desktop video plus static tablet/mobile fallback;
3. fully static industrial Hero visual;
4. stronger category/project visuals lower on the page while keeping Hero simple.

### Recommended Temporary Decision

Keep the current video for now.

Do not replace the Hero video immediately.

Do not generate final Hero visuals yet.

Include Hero media strategy in a later visual asset phase.

## What We Support Visual Strategy

### Current State

The section uses three text cards.

### Visual Goal

Explain the operating range:

1. individual equipment;
2. production lines and modernization;
3. integrated industrial project support.

### Current Decision

No additional visual implementation is required immediately.

## Project Capabilities Visual Strategy

### Current State

The section uses a static abstract placeholder and four capability cards.

### Visual Goal

Support the idea that a serious equipment request is shaped by:

* requirements;
* equipment and line planning;
* logistics;
* installation context.

### Constraint

A detailed process diagram is not appropriate in the current small visual space.

### Recommended Direction

Use a symbolic technical visual rather than a complex diagram.

The visual can imply:

* structured process;
* technical coordination;
* material flow;
* planning discipline.

### Future Visual Type

Preferred options:

* simplified technical panel;
* abstract process motif;
* partial equipment/process context image;
* subdued industrial planning visual.

### Avoid

Do not use dense diagrams with small unreadable text.

Do not use fake UI dashboards.

Do not use charts that imply unsupported data.

## Industrial Inquiry Discipline Visual Strategy

### Current State

This is a dark, text-heavy authority section.

### Visual Goal

Communicate that Mall Agro follows a professional, structured, quote-based inquiry approach.

The visual should reduce visual heaviness without distracting from the message.

### Current Issue

The dark block is useful for authority but visually heavy.

### Recommended Future Direction

Consider a subtle technical visual treatment, such as:

* low-opacity background pattern;
* abstract process line;
* industrial detail image under dark overlay;
* simple technical motif.

### Avoid

Do not use a complex process diagram in limited space.

Do not use images that compete with text contrast.

Do not reduce readability.

## Inquiry Process Visual Strategy

### Current State

The section uses intro text and four process steps.

### Desired Future Layout Direction

The section should be considered for a controlled layout refinement:

* left side: eyebrow, title, explanatory text;
* right side: supporting visual;
* below: four process steps.

### Step Card Issue

Current process step cards have too much empty space between the step number and the text.

### Recommended Future Refinement

In a future implementation task:

* increase the visual weight of the step numbers;
* reduce excessive empty space;
* keep the four-step list readable;
* preserve the current four-step process logic.

### Future Visual Type

The visual should support the inquiry process without becoming a detailed diagram.

Preferred options:

* abstract process visual;
* light technical motif;
* equipment inquiry context image;
* subdued industrial planning visual.

## Final CTA Visual Strategy

### Current State

The Final CTA uses a dark block.

### Proposed Experiment

Test a very subtle background visual under a dark overlay.

The image should be almost hidden and should not compete with the text.

Possible visual direction:

* modern agricultural / industrial field context;
* silos or grain facility in the distance;
* broad industrial landscape;
* neutral project-oriented background.

### Decision

This should be treated as an experiment.

If the visual distracts, reduces readability, or feels decorative, remove it.

### Requirements

CTA text must remain clearly readable.

CTA button must remain prominent.

The visual must not imply unsupported project ownership or client identity.

## Footer Strategy

The footer is outside the current homepage visual strategy.

A more serious footer will be required later.

Footer planning should happen after the main homepage semantic and visual structure is stable.

Do not start footer implementation in the next immediate task.

## Immediate Next Priority

Do not start final image generation.

Do not start Hero video replacement.

Do not start footer implementation.

1. Inquiry Process layout refinement;
2. Industrial Inquiry Discipline visual lightening;

* preserve localization rules;
* avoid route, SEO, metadata, and slug changes unless separately approved;
* avoid broad redesign language;
